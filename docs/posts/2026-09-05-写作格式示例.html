写作格式示例

2026-09-05 · 说明

这篇是格式说明书。你可以把它当成模板，写新文章的时候照着抄。

看腻了随时删掉这个文件，博客不会出问题。

一、小标题

行首写 ## 加一个空格，就是二级标题。写 ### 是三级小标题。

二、文字样式

  • **加粗** 会显示成 加粗
  • *斜体* 会显示成 斜体
  • ~~删除线~~ 会显示成 删除线
  • 反引号包起来会显示成行内代码，比如 npm install

三、列表

无序列表，行首用 - 加空格：

  • 第一件事
  • 第二件事
  • 第三件事

有序列表，行首用 1. 加空格：

  1. 早上起床
  2. 吃早饭
  3. 出门

四、引用

行首写 > 加空格，会变成引用块，适合放一句话：

慢慢来，比较快。

五、分割线

单独一行写三个减号，会出现一条横线：

六、链接和图片

链接写法是 [显示的文字](网址)，例如 去百度看看。

图片写法是 ![图片说明](图片地址)。图片地址可以是网上的链接：

如果想把图片存在自己电脑上，就把图片放进 images 文件夹，然后写 ![说明](images/图片名.jpg)。生成网站的时候，图片会被自动复制过去，不用你操心路径。

七、代码块

三个反引号单独一行，包住一段代码：

def hello(name):
    print("你好，" + name)

hello("世界")

不写语言名也可以，效果一样，只是没有高亮。

八、换行和分段

空一行表示另起一段。

在同一个段落里换行，也会正常换行显示，所以你可以放心地一句一行地写。

看懂了吗？其实只需要记住两件事：空一行分段，以及行首加 ## 是标题。剩下的想用了再回来查。
